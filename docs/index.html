One tab, three ways to look at it

Pick a gradient, a flat colour, or a photo. The interface works out its own contrast, so a pale background stays readable instead of being forbidden.

The last version shipped a tracker wearing an icon.

Every bookmark tile used to fetch its icon from Google, on every new tab. That handed Google the list of sites you had pinned and a heartbeat of how often you opened a tab. It is gone. Icons now resolve on your own machine.

Accounts
None. There is nothing to sign in to.
Telemetry
None. No analytics, no crash pings.
Your data
Stays in your browser profile.
Network access
Only when you search or turn on photos.

Built so you can change your mind

26 search engines, privacy-forward first

DuckDuckGo and Brave lead the list. Every engine carries an honest badge, so you can see which ones build a profile of you before you pick one. Type ct in the address bar to search without opening a tab at all.

Bookmarks you edit in place

Add, rename, delete and drag to reorder, right on the tab. No settings round trip.

Or skip the dashboard

Point the new tab at any URL you like, including a local file or another extension page.

Sunrise reveal

The background rises and blooms as the tab opens. It steps aside automatically if your system asks for reduced motion.

Sync is opt-in

Mirror your settings across devices if you want to. Bookmarks stay on the machine they belong to.

Photo backgrounds, on your own key

Point it at Pexels with a search term and get a new photo every day, every hour, or every single tab. The photographer is always credited.

You supply the API key, because anything bundled into an extension is public. It is stored on your device, never synced, and sent only to Pexels. One request caches a page of photos that is then shuffled locally, so even the most frequent setting touches the network a few times a day.

Install it

Store listings are in review. Until they are live, the packages from the latest release install in a minute.

Download v1.2.1 View source
  1. Chrome, Edge or Brave. Unzip custm-tab-chrome-1.2.1.zip, open chrome://extensions, turn on Developer mode, then choose Load unpacked and select the folder.
  2. Firefox. Open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on, and select manifest.json from the unzipped Firefox package.
  3. That is it. A setup wizard opens on first run. Four steps, then your tab is yours.
