Bookmark icons

How the tile icons on your dashboard are resolved.

Why this setting exists›

Earlier versions fetched every tile icon from Google, which handed Google the list of sites you had pinned and a signal every time you opened a tab. That contradicted the privacy promise, so it is gone.

On this device uses the browser own icon cache in Chrome, and falls back to letter tiles in Firefox, which has no equivalent. Letter tiles never touch the network at all. Fetch from DuckDuckGo discloses each bookmark hostname and nothing else — path, query and fragment are never sent.

Using a local file?›
  1. Open chrome://extensions (or about:addons in Firefox)
  2. Find cust*m Tab and open its Details
  3. Turn on "Allow access to file URLs"
  4. Enter a path such as file:///C:/Users/you/page.html

Browsers restrict file:// access for security reasons. You only need to set this once.
